# yaklass-solver

> **Важно.** Автоматическое выполнение работ нарушает правила ЯКласса: аккаунт могут ограничить, учитель может заметить
> результат. Проект — демонстрация (proof of concept) того, как просто такие работы решаются ИИ. Всё, что вы делаете, —
> на Вашу ответственность. Пароль от ЯКласса приложению не нужен и никому не передаётся.

`yaklass-solver` - автоматизированная утилита для решения ЯКласс работ через ИИ агентов без участия пользователя.

## Возможности

Готовое GUI приложение для клиента, полная автоматизация, управление через телеграм бота (нужно открытое приложение на машине пользователя), простая установка на свой сервер. Выполнение заданий обеспечивает ИИ, вы можете использовать как локальную модель, так и API (в приложении используется OpenAI-compatible API для связи с ннейросетью).

## Установка

### Локально + GUI

Скачайте готовый исполняемый файл из релизов, запустите и настроить приложение. Полная инструкция - docs/CLIENT.md

### Локально (CLI)

1. Клонируйте репозиторий.
2. Запустите install-cli.sh или install-cli.ps1 в зависимости от Вашей ОС.
3. Пропишите в консоли `yaklass-bot --help`, изучите доступные команды.
4. Настройте утилиту - `yaklass-bot setup`.
5. Наслаждайтесь :)

### Сервер

> Для установки на сервер нужен белый IP/проброс 443 и 80 портов.

1. Клонируйте репозиторий.
2. Запустите install-server.sh (потребуется root).
3. Клонируйте .env.example как .env файл.
4. Заполните .env файл.
5. Запустите сервис.
6. Пробросьте IP через nginx/Caddy.
7. Наслаждайтесь :)

Полная инструкция - docs/SERVER.md

## Q&A

Q: Мой аккаунт украдут?
A: Нет. Куки файлы не передаются серверу с Вашего компьютера, а логин и пароль вообще не используются.

Q: Меня могут забанить за использование этого приложения?
A: Да, это прописано в дисклеймере. Все действия Вы осуществляете на свой риск, автоматическое выполнение работ нарушает правила площадки (ToS), аккаунт может быть ограничен. Я не несу ответственность за Ваши действия.

Q: Во время разработки использовался ИИ?
A: Да. Более того, почти всю работу выполнил именно ИИ, человеческие правки вносились, но далеко не всегда.

Q: Я столкнулся с ошибкой/у меня есть идея по улучшению.
A: Создайте Issue с описанием бага или своим предложением.
