# Руководство пользователя

> **Важно.** Автоматическое выполнение работ нарушает правила ЯКласса: аккаунт могут ограничить, учитель может заметить
> результат. Проект — демонстрация (proof of concept) того, как просто такие работы решаются ИИ. Всё, что вы делаете, —
> на вашу ответственность. Пароль от ЯКласса приложению не нужен и никому не передаётся.

## 1. Выберите сценарий

| Сценарий | Нужен сервер? | Что понадобится |
|---|---|---|
| **A. Только у себя, без сервера** | нет | приложение + ключ любого OpenAI-совместимого API (или локальная модель) |
| **B. Подключиться к чужому серверу** | чужой | приложение + Telegram + адрес сервера от его владельца |
| **C. Развернуть свой сервер** | свой | Linux-сервер, Telegram-бот, ключ модели; клиент подключается к нему |
| **D. Консольная версия** | нет | Python и терминал, без окна приложения |

В сценариях B и C управлять работами можно и из Telegram (список, запуск, пауза, стоп). Сервер **не видит** ваш аккаунт ЯКласса:
вход, куки и все запросы к сайту выполняет приложение на вашем компьютере. На сервер уходят только тексты заданий (для решения).

## 2. Установка приложения

Скачайте последний релиз со страницы **Releases** репозитория.

### Windows
1. Скачайте `YaklassSolver.exe` и запустите двойным щелчком.
2. Если Windows пишет «Система Windows защитила ваш компьютер» (файл не подписан) — **Подробнее → Выполнить в любом случае**.
3. Браузер для работы по умолчанию — Microsoft Edge (он уже есть в Windows). Можно выбрать Chrome в настройках.

### Linux
1. Скачайте `YaklassSolver-x86_64.AppImage` и разрешите запуск: `chmod +x YaklassSolver-x86_64.AppImage`.
2. Запустите `./YaklassSolver-x86_64.AppImage`.
3. Если не запускается с ошибкой про FUSE: `sudo apt install libfuse2` (Ubuntu 24.04: `libfuse2t64`) или запустите
   `./YaklassSolver-x86_64.AppImage --appimage-extract-and-run`.
4. Нужен браузер: установленный Google Chrome (используется автоматически) или встроенный Chromium — его можно скачать
   кнопкой в **Настройки → Браузер** (≈150 МБ).

### Из Python (если готовая сборка не подходит)
```bash
pip install "yaklass_bot-<версия>-py3-none-any.whl[gui]"   # wheel из Releases
playwright install chromium                                  # браузер, если нет Chrome/Edge
yaklass-app
```
Нужен Python 3.11 или новее.

## 3. Первый запуск и вход в ЯКласс (для всех сценариев)

1. Откройте приложение. Слева — разделы **Главная, Работы, Настройки, Журнал**.
2. **Настройки → Браузер → «Откуда брать вход в ЯКласс»**:
   - **Собственный профиль приложения** (рекомендуется): на главной нажмите **«Войти в ЯКласс»**, в открывшемся окне войдите в
     свой аккаунт и закройте окно. Вход запоминается.
   - **Куки из моего браузера**: войдите в ЯКласс в выбранном браузере (например, Firefox), закройте его и нажмите
     **«Проверить вход»**. На Windows с новым Chrome куки часто не читаются — берите профиль приложения или Firefox.
3. **Не отключайте «Показывать окно браузера»**: скрытый режим сайт может отклонять (ошибка «403 подозрительная активность»).
4. Откройте **Работы** → **«Обновить»**: появится список новых работ. Приложение само ничего не проверяет в фоне, пока вы не
   включите «Сам проверять новые работы» в настройках (откроет окно браузера на несколько секунд).

## 4. Сценарий A: без сервера, на своём компьютере

Приложение работает **полностью автономно**: ответы получает от модели напрямую с вашего ПК, сервер и Telegram не нужны.

1. **Настройки → Решатель ответов → «Свой API»**. Заполните:
   - **Адрес API** — любой OpenAI-совместимый (`…/v1`):
     | Сервис | Адрес | Пример модели |
     |---|---|---|
     | OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
     | DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
     | OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
     | Ollama (на этом ПК) | `http://localhost:11434/v1` | модель, которую вы скачали |
   - **Модель** и **Ключ API** (хранится только на вашем компьютере: в системном хранилище паролей или в файле с правами 600).
     Локальным серверам вроде Ollama ключ не нужен.
   - **Vision** — включите, если модель понимает картинки (иначе задания с рисунками будут решаться «вслепую»).
   - **Режим JSON** — полезен для Ollama и DeepSeek; если сервер ругается на него, выключите.
   - **SearXNG** (необязательно) — адрес вашего поискового сервера; тогда перед ответом приложение ищет в сети (рекомендуется
     для заданий на знание фактов). В SearXNG должен быть включён формат `json`.
2. Нажмите **«Сохранить»**.
3. **Работы** → у нужной работы:
   - **«Только заполнить»** — приложение выставит ответы, но **не отправит**: проверьте и нажмите «Ответить» сами. С этого и начните.
   - **«▶ Выполнить»** — автономно: само начнёт работу, ответит на все задания (уже выполненные перезапишет) и завершит её.
     Это необратимо и может потратить попытку.
4. Ход выполнения виден на **Главной** и в **Журнале**; есть **Пауза** и **Стоп**.

Советы:
- Небольшие локальные модели хуже справляются с математикой и ошибаются с уверенным видом; смотрите «Основание» в журнале.
- Для Ollama увеличьте контекст (по умолчанию он короткий): `OLLAMA_CONTEXT_LENGTH=8192`.
- Если работа не завершилась автоматически (часть заданий не решена), окно браузера остаётся открытым — доделайте вручную.

## 5. Сценарий B: подключиться к существующему серверу

1. Узнайте у владельца сервера **адрес** (например, `https://solver.example.com`) и **имя Telegram-бота**.
2. В приложении: **Настройки → Сервер → «Адрес сервера»** → **Сохранить**.
3. В Telegram откройте бота и отправьте `/start`, затем `/link`. Бот пришлёт **адрес сервера и одноразовый код** (действует
   10 минут). Если у сервера включена регистрация по приглашению, сначала используйте ссылку-приглашение владельца.
4. В приложении, на **Главной**, введите код и нажмите **«Привязать»**. Статус станет «Подключено · @ваше_имя».
5. Решатель: по умолчанию **«Сервер»** (общий ключ модели у владельца, у вас есть суточный лимит). Можно выбрать **«Свой API»**:
   тогда запросы к модели идут с вашего ПК, а сервер нужен только для управления из Telegram.

Бот не знает ваш аккаунт ЯКласс и ничего с ним не делает сам: он лишь передаёт команды приложению, которое должно быть
**запущено** на вашем компьютере.

### Команды бота
| Команда | Что делает |
|---|---|
| `/link` | код привязки приложения |
| `/unlink` | отвязать все приложения |
| `/status` | подключено ли приложение, лимит запросов, состояние |
| `/works` | список новых работ (кнопки «Автономно» / «Только заполнить») |
| `/pause`, `/resume`, `/stop` | управление выполнением |

Запуск работы из Telegram можно запретить: **Настройки → Приложение → «Разрешить запуск работ командой из Telegram»**.

## 6. Сценарий C: развернуть свой сервер

### Что нужно
- Linux-сервер (Ubuntu 22.04+), Python 3.11+, `git`, исходящий доступ к Telegram и к API модели.
- Токен Telegram-бота: в Telegram откройте **@BotFather → `/newbot`**, придумайте имя и получите токен.
- Ключ API модели (любой OpenAI-совместимый сервис).
- Для доступа из интернета: домен и nginx с HTTPS. Для домашней сети можно без них (см. ниже).

### Шаги
```bash
git clone https://github.com/<владелец>/yaklass-solver.git /opt/yaklass-solver && cd /opt/yaklass-solver
bash deploy/install-server.sh --systemd     # окружение, зависимости, .env, база, служба systemd
nano .env                                    # заполните, см. ниже
sudo systemctl restart yaklass-solver        # именно restart: reload у службы ничего не делает
journalctl -u yaklass-solver -f              # журнал
```
Скрипт безопасно запускать повторно; он не перезаписывает `.env` и базу. Без systemd: `.venv/bin/yaklass-server`.

### Главное в `.env`
| Переменная | Значение |
|---|---|
| `DOMAIN` | домен сервера (показывается пользователям в `/link`); `PUBLIC_URL` — полный адрес, если он другой |
| `HOST`, `PORT` | где слушает сервис (по умолчанию `127.0.0.1:8080`; наружу его отдаёт nginx) |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ваши Telegram id через запятую (проходят регистрацию всегда); свой id можно узнать у бота @userinfobot |
| `REGISTRATION` | `open` — любой, `invite` — по приглашению, `closed` — только добавленные вами |
| `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY` | общая модель для всех пользователей; `LLM_VISION`, `LLM_JSON_MODE` — как в приложении |
| `DAILY_QUOTA`, `RATE_PER_MIN`, `MAX_CONCURRENT_SOLVES` | лимиты: **расходы на модель оплачиваете вы** |
| `SEARXNG_URL`, `SEARCH_MODE` | поиск перед ответом (`always` / `model` / `off`) |

Комментарии в `.env` пишите отдельными строками, не в конце строки со значением.

### nginx и HTTPS
Скопируйте `deploy/nginx.conf.example` в конфигурацию nginx, подставьте домен, порт из `.env` и пути к сертификату
(например, Let's Encrypt). **Блок `location /v1/agent` с `Upgrade`/`Connection "upgrade"` обязателен**: без него приложения не смогут
подключиться (в журнале будет «Handshake status 404»).
```bash
sudo nginx -t && sudo systemctl reload nginx
curl https://ваш-домен/healthz                         # {"ok":true,...}
curl -i -N --http1.1 -H "Connection: Upgrade" -H "Upgrade: websocket" -H "Sec-WebSocket-Version: 13" \
     -H "Sec-WebSocket-Key: SGVsbG8sIHdvcmxkIQ==" https://ваш-домен/v1/agent     # должно быть HTTP/1.1 101
```

### Вариант без домена (домашняя сеть)
Бот работает без публичного адреса (он сам опрашивает Telegram). Для приложений в той же сети задайте в `.env`
`HOST=0.0.0.0` и `PORT=8080`, откройте порт на сервере, а в приложении укажите `http://<IP сервера>:8080`. Трафик без HTTPS
идёт открытым текстом, поэтому используйте это только в доверенной сети.

### Управление пользователями (`yaklassctl`)
```bash
cd /opt/yaklass-solver
.venv/bin/yaklassctl stats
.venv/bin/yaklassctl users list                    # users add|ban|unban <tg_id>, users quota <tg_id> <N|default>
.venv/bin/yaklassctl agents list                   # agents revoke <id>, agents revoke-user <tg_id>
.venv/bin/yaklassctl invite create --uses 5        # код приглашения; ссылка для пользователя: https://t.me/<бот>?start=<код>
```

### Обновление сервера
```bash
cd /opt/yaklass-solver && git pull && bash deploy/install-server.sh --systemd
```

### Резервная копия
`sqlite3 data/server.db ".backup backup.db"` (в базе нет ни кук, ни паролей ЯКласса, только Telegram id и хеши токенов).

## 7. Сценарий D: консольная версия (без окна)

```bash
sh install-cli.sh                       # Windows: install-cli.ps1 (нужен uv или pipx)
yaklass-bot setup                       # мастер: браузер, API (OpenAI/DeepSeek/OpenRouter/Ollama), vision, SearXNG
yaklass-bot run --dry-run               # открыть работу, выставить ответы, НЕ отправлять
yaklass-bot run "<ссылка>" --auto       # выполнить автономно (запросит подтверждение; --yes — без вопроса)
```
Полезные параметры `run`: `--no-start` (не нажимать «Начать»), `--resume` (пропустить уже отправленные), `--finish-anyway`.
Без ссылки откроется список работ. Настройки лежат в `config.toml` (папка настроек ОС).

## 8. Обновление приложения

При запуске (и раз в 12 часов) приложение проверяет релизы. Если вышла новая версия, на **Главной** появится плашка
**«Доступна новая версия»**: нажмите **«Обновить сейчас»** — файл скачается, проверится контрольная сумма и приложение
перезапустится. Нельзя обновляться во время выполнения работы. Из Python: `pip install -U …`. Проверку можно отключить
или запустить вручную: **Настройки → Приложение**.

## 9. Если что-то не работает

| Симптом | Что делать |
|---|---|
| AppImage не запускается | `sudo apt install libfuse2` или `--appimage-extract-and-run` (см. раздел 2) |
| «Не найден браузер для выполнения» | установите Chrome/Edge, либо **Настройки → Браузер → «Скачать Chromium»**, либо укажите «Путь к браузеру» |
| «Нужно войти» / «Не удалось проверить» | войдите заново кнопкой на главной; в режиме кук — войдите в браузере, закройте его, «Проверить вход»; прочитайте причину под статусом |
| «403 подозрительная активность» / «проверка вы не робот» | включите «Показывать окно браузера»; не запускайте много работ подряд; откройте ЯКласс в обычном браузере и пройдите проверку; если не проходит — подождите и напишите в поддержку ЯКласса |
| «Handshake status 404» (связь с сервером) | в nginx сервера нет WebSocket-блока `/v1/agent` (раздел 6) |
| Бот не отвечает на команды | приложение должно быть запущено и подключено; `/status`; для владельца сервера: `journalctl -u yaklass-solver -n 50` |
| «Дневной лимит исчерпан» | лимит сервера на пользователя; попросите владельца увеличить (`yaklassctl users quota`) или выберите «Свой API» |
| После обновления сервера бот не изменился | на сервере нужен `git pull` **и** повторный `bash deploy/install-server.sh --systemd` (restart, не reload) |
| Windows: SmartScreen | Подробнее → Выполнить в любом случае (файл не подписан) |
| Привязка пропала после перезапуска | обновитесь до последней версии (раньше ошибка с хранилищем паролей) |

Подробности всегда в **Журнале** приложения.

## 10. Где хранятся данные и как всё удалить

| Что | Где |
|---|---|
| Настройки, токен привязки/ключ API (если нет хранилища паролей) | Linux: `~/.config/yaklass-solver/`; Windows: `%LOCALAPPDATA%\yaklass-solver\yaklass-solver\` |
| Профиль браузера и вход в ЯКласс, снимок кук, учёт работ, снимки итогов | Linux: `~/.local/share/yaklass-solver/`; Windows: `%LOCALAPPDATA%\yaklass-solver\yaklass-solver\` |
| Токен и ключ API (если есть системное хранилище) | в связке ключей ОС, запись `yaklass-solver` |

Полное удаление: закройте приложение, удалите файл приложения, обе папки выше и записи `yaklass-solver` в хранилище паролей;
в Telegram отправьте боту `/unlink`.

## 11. Что видит сервер и что остаётся у вас

- **Остаётся у вас:** пароль, куки и сам вход в ЯКласс, профиль браузера, ключ вашего API (в режиме «Свой API»).
- **Видит сервер (режимы B и C):** ваш Telegram id и имя, хеш токена приложения, число запросов за день и **тексты заданий**,
  которые приложение отправляет на решение (по умолчанию в журнал сервера они не пишутся, `LOG_TASKS=false`).
- Никому не передавайте код из `/link`, токены и ключи API.
