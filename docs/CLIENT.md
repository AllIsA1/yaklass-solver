# Гайд для клиента

Приложение работает **на вашем компьютере**: вход в ЯКласс, куки и все запросы к сайту остаются у вас,
сервер видит только тексты заданий (для решения) и служебные события. Управление — из окна приложения
или из Telegram-бота.

## Скачайте из **Releases** подходящий для вашей ОС файл: 

Windows - `YaklassSolver.exe`

Linux - `YaklassSolver-x86_64.AppImage`

Если не подходит — Python-версия:
```bash
pip install "yaklass_bot-*-py3-none-any.whl[gui]"
```

## Первый запуск
1. **Настройки → Сервер**: адрес, который дал администратор бота (`https://…`).
2. В Telegram боту `/link` → код → вкладка **Главная** → «Привязать».
3. **Главная → Войти в ЯКласс**: откроется окно браузера, войдите в аккаунт и закройте окно.
4. **Работы** → «Выполнить» (завершить) или «Только заполнить» (не завершать).

## Что в настройках
- **Решатель:** *Сервер* (общий API, суточный лимит) или *Свой API* (OpenAI, DeepSeek, OpenRouter, Ollama…;
  запросы идут прямо с вашего ПК, ключ хранится в системном хранилище паролей или файле)
  Для своего API можно подключить SearXNG и выбрать режим поиска.
- **Задержки:** пауза между заданиями, перед «Ответить», между полями, скорость набора. Сервер может
  задать минимальную паузу между заданиями.
- **Браузер:** собственный профиль приложения (рекомендуется) или куки вашего браузера; окно браузера — показывать/скрывать.
- **Приложение:** разрешить запуск работ из Telegram, как часто искать новые работы, тема.

## Как это работает
`Агент` держит WebSocket-соединение с сервером (исходящее, порты открывать не нужно), раз в N минут ищет новые
работы и сообщает о них в Telegram. Команды из бота (`list_works`, `start_work`, `pause`,
`resume`, `stop`, `status`) — единственное, что сервер может попросить.
Выполнение: «Начать/Продолжить» → задания с первого по последнее (уже выполненные перезаписываются кнопкой
«Сохранить») → «Завершить». Если хотя бы одно задание не удалось, работа **не завершается**, окно остаётся
открытым для ручного завершения. Лимит или недоступность сервера останавливают прогон.

### Режимы выполнения
Выбираются при запуске (кнопка «Выполнить» в приложении, кнопки или `/stealth` в Telegram):
- **Обычный** — паузы из «Настроек».
- **Быстрый** — минимальные паузы.
- **Скрытный** — за заданное время и на заданную оценку (3: 53–75%, 4: 76–90%, 5: 91–100%). Бот сам решает,
  какие задания решить верно, какие оставить без ответа, какие решить неверно, а какие — частично; процент
  берётся случайно внутри диапазона и считается по баллам за задания. Если время «ровное» (целые минуты), оно
  смещается не больше чем на ±57 с; при лимите времени у работы цель уменьшается так, чтобы остался запас.
  Работа завершается, даже если часть заданий оставлена без ответа (путь завершения с недоотвеченной работы
  пока не проверен на живом сайте). Оценка **ожидаемая**: верность ответов модели заранее неизвестна, а сайт
  правильность не показывает.

## Защита ЯКласса от автоматических запросов
У сайта есть защита от ботов, обычный HTTP-запрос получит страницу-заглушку с JS-проверкой. На этот случай у утилиты есть отдельная настройка - "показывать окно браузера" (лучше не отключать). Также, во избежание блокировки IP, приложение по умолчанию не обновляет работы автоматически.

**Вход в ЯКласс.** 
Куки входа сессионные: Chromium не сохраняет такие куки при закрытии браузера, поэтому приложение
хранит снимок кук профиля (`session-cookies.json` в папке данных приложения) и возвращает их при следующем
запуске. Режим «куки браузера» читает куки из выбранного браузера (Firefox, Chrome и др.) и передаёт их запущенному браузеру.

## Обновления
Приложение при запуске (через 20 с и далее раз в 12 часов) смотрит последний релиз в GitHub Releases. Если он новее,
на главной странице появляется плашка «Доступна новая версия» с описанием.
