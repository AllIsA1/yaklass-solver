# Расширение для браузера

Тот же Yaklass Solver, но работа выполняется **в вашем обычном браузере** (Chrome, Chromium, Edge, Brave, Vivaldi, Opera),
а не отдельным окном приложения. Решает задания тот же сервер (квоты, запасная модель, режим для английского), управлять можно
так же из Telegram.

Чем это удобнее приложения: не нужен Chromium Playwright, не нужно импортировать куки (вы уже вошли в ЯКласс в этом браузере),
запросы идут с настоящим профилем и User-Agent вашего браузера.

## Установка (режим разработчика)
1. Скачайте `YaklassSolver-extension.zip` со страницы релиза и **распакуйте в постоянную папку** (удалять её нельзя).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`), включите **«Режим разработчика»**.
3. **«Загрузить распакованное»** → выберите папку, в которой лежит `manifest.json`.
4. Закрепите значок расширения на панели.

**Обновление — вручную:** скачайте новый архив, замените файлы в той же папке и нажмите «Обновить» (⟳) на карточке расширения
в `chrome://extensions`. Если вышла новая версия, в окне расширения появится плашка со ссылкой на релиз.

## Первый запуск
1. Войдите в ЯКласс (yaklass.ru) в этом браузере.
2. Боту в Telegram — `/link`, он пришлёт **код подключения** вида `домен:код`.
3. Значок расширения → вставьте код → «Привязать». Браузер спросит разрешение на доступ к адресу сервера из кода — это нужно один раз.
4. Вкладка **Работы** → «Обновить» (расширение откроет список работ в фоновой вкладке) → «Выполнить» / «Быстро» / «Только заполнить».
   Или командой из Telegram: `/works`, затем кнопки.

Во время выполнения расширение открывает вкладку с работой; **не закрывайте её**. Пауза и стоп — в окне расширения или `/pause`,
`/resume`, `/stop`.

## Что умеет
- Обычный и быстрый режимы; «Только заполнить» (без отправки).
- Задания: текстовые поля и поля формул, выбор одного/нескольких вариантов, выпадающие списки; теория («Прочитано»).
- Завершение работы обеими разновидностями страницы (форма и кнопка с окном подтверждения), чтение реальных баллов и названия работы.
- История запусков (название, время, процент, баллы) и журнал — в окне расширения; итоговое сообщение в Telegram — как у приложения.

## Пока не умеет
- **Скрытный режим** (время и оценка): команда из бота отклоняется с понятным сообщением — используйте приложение.
- **Перетаскивание**: такие задания пропускаются как «без поддержки», работа остаётся не завершённой (доделайте вручную).
- Firefox: нужна отдельная сборка (подписанный `.xpi`), пока не делали.
- Расширение живёт, пока браузер открыт. Если браузер закрыть во время работы, она прервётся.

## Как устроено
`src/parser.js` — разбор страниц (порт Python-парсера, сверяется с ним на одних и тех же страницах), `src/filler.js` и
`src/content.js` — работа внутри страницы ЯКласса, `src/runner.js` — цикл выполнения работы, `src/background.js` — связь с
сервером (WebSocket `/v1/agent`, как у приложения), команды из Telegram и история. Протокол — [PROTOCOL.md](PROTOCOL.md).
Адрес сервера хранится в `chrome.storage` и в окне не показывается.

## Для разработчиков
```bash
node --test extension/tests/connect.test.mjs      # логика кода подключения
pytest tests/test_extension_parser.py tests/test_extension.py   # парсер против Python-версии и сквозной прогон в Chromium
cd extension && zip -r ../YaklassSolver-extension.zip . -x "tests/*"                      # архив для релиза
```
Версия расширения (`extension/manifest.json`) должна совпадать с версией проекта — это проверяют тест и сборка релиза.
